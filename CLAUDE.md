# Git

- Commit and push straight to `main`. Do not create or push any other branch on GitHub
  (the session can't delete remote branches, so they pile up). Ignore a session-assigned
  feature branch for pushing: work locally, then `git push origin HEAD:main`.
- No pull requests unless asked.

# Layout

One folder per project (see README.md): `avocado-tv/` (page `index.html`, data `tiktok/` `drive/`,
WebView app `android/` -> `tv.apk`, `scripts/`), `tre-em/` (kids' games), `fingerstyle/`, `1011-tv/`
(launcher for the FPT Play box, its own CLAUDE.md). Root `tv.html`, `can-dia.html`, `dong-ho.html`,
`hoc-dong-ho.html` are redirects to the new places; keep them.
